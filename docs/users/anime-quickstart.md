# HSC Anime Edition 上手（用户）

面向 Emby 管理员的简短说明。详细规则见 [动漫合集](../features/anime-collections/README.md)。

## 与官方插件的关系

本版是官方 Home Screen Companion 的个人 Fork（Anime Edition），**请勿与官方插件同时启用**。两边的计划任务名称相同，同时装开会让「运行」菜单点到错误任务。

建议迁移：

1. 在本版（或官方）中导出插件备份  
2. 卸载官方 Home Screen Companion  
3. 安装本版插件并重启 Emby  
4. 导入备份；核对动漫批准名单、成员规则与别名  
5. 先开「仅预览」再跑动漫合集同步

问题请到 [本版 Issues](https://github.com/kiwi4814/HSC-Anime-Edition/issues) 反馈，不要直接开给官方仓库。

## 动漫合集五步

1. **设置 → 动漫合集** → 勾选「启用动漫合集」，建议保持「动漫合集仅预览」先开着。  
2. 页面右下角 **运行 → 动漫合集同步**（或 Emby 计划任务）。  
3. 打开 **日志 → 动漫**，查看候选合集 Key 与跳过原因。  
4. 把要创建的合集 Key 粘贴到「批准名单」；需要时再填成员规则 / 合集别名。  
5. 关闭仅预览（或关闭全局「仅预览」）后再次运行，才会真正创建/更新合集。

插件只管理自己创建的合集，不会改动你手工建的合集。

## 仅预览

全局「仅预览」会同时挡住：标签/合集同步、动漫合集写入、**主屏幕同步**（不删不改用户主屏幕与媒体库顺序）。动漫面板上的「动漫合集仅预览」只影响动漫任务。

## 备份

勾选「设置」导出时，批准名单、成员规则、别名会一起带走。合集归属文件（`owned-collections.json`）**不在**备份里；换机器后需要重新预览并批准。

## 网络与映射

首次同步会下载 AniBridge 映射（默认 GitHub）。若服务器访问不了 GitHub：在「映射数据地址」填可用镜像，或把 `mappings.min.json` 手动放到插件数据目录的 `anime/anibridge-v3.json`。

## AI（可选）

命名 / 合集审查 / 关系复核默认关闭。开启后只出建议，不自动改合集。合集审查会把相关作品名称与外部编号发给所选 AI，**不会**把整库未识别作品整批送出。

## 常见问题

| 现象 | 建议 |
|---|---|
| 日志里很多「已跳过」 | 看跳过原因：未在批准名单、需人工核对、与手工合集重名等 |
| AniList「请再次运行」 | 配额用完；隔一会儿再跑，会接着拉关系缓存 |
| 「作品关系超过上限」 | 库太大触到节点上限；缩小范围或等待后续版本 |
| 合集没出现 | 确认已关闭仅预览、Key 在批准名单、任务跑的是本版插件 |
