系统提示词是在每次请求前发送给 AI 的隐藏指令。它告诉模型应扮演什么角色，最关键的是，要求它以插件可解析的特定 JSON 格式回复。

请仅在了解其作用时修改。如果删除或更改 JSON 格式要求，插件将无法读取 AI 的回复，列表也会显示为空。

功能一览
此插件有什么作用？
Home Screen Companion 可自动更新您的 Emby 主屏幕。连接电影列表（来自 Trakt、MDBList 等网站，或您自己的筛选器）后，插件会为 Emby 媒体库中的对应电影添加标签。这些标签可用于创建“当前热门”或“十大动作电影”等自定义主屏幕栏目，并按计划自动更新。

rocket_launch 快速入门
1
输入 API 密钥 — 前往设置选项卡。API 密钥是一段允许插件代表您访问服务的代码，可将其理解为插件的密码，而非您的个人密码。只需添加您打算使用的服务的密钥。
Trakt: 前往 trakt.tv/oauth/applications 并登录。 点击新建应用，任意命名，然后在重定向 URI字段中准确输入：http://localhost （这只是必填的占位地址，无需访问）。 点击保存，然后复制客户端 ID并粘贴到此处。
MDBList: 前往 mdblist.com/preferences， 向下滚动到 API 访问部分，复制您的 API 密钥。
TMDb: 前往 themoviedb.org/settings/api， 滚动到 API 读取访问令牌，复制较长的令牌，而非上方较短的 API 密钥。公开的 TMDb 列表无需令牌即可使用。
OpenAI / Gemini: 仅在使用 AI 生成列表来源类型时需要。 API 密钥字段默认隐藏，勾选各字段旁的显示复选框即可查看已输入的内容。
2
添加来源 — 打开标签与合集选项卡，点击 + 添加新来源。来源就是插件获取电影列表的地方。
3
配置来源 — 每个来源都有多个选项卡：
  • 来源 — 选择列表的获取位置（Trakt URL、MDBList URL、本地合集等）
  • 标签 — 设置要应用于 Emby 中匹配电影的标签名称
  • 合集 — 也可将电影归入 Emby 合集
  • 计划 — 可限制此来源的启用时间（例如仅在 12 月）
4
保存并运行 — 点击页面底部的保存设置，再点击底部的运行按钮并选择完整同步。插件将获取列表、匹配媒体库中的电影并应用标签。完成！
input 来源类型
来源是插件获取电影或剧集列表的地方。每个来源都关联一个标签；插件获取列表后，会为 Emby 媒体库中匹配的项目添加该标签。请按您构建列表的方式选择来源类型：
public 外部
粘贴 Trakt、MDBList 或 TMDb 的列表 URL。插件会下载列表，并为媒体库中找到的所有匹配项目添加标签。同一来源可添加多个 URL，它们将合并为一个列表。
TMDb 有两种用法：
  • 您自己的列表 — 粘贴您在 themoviedb.org 上创建的任意公开或私有列表的 URL。
  • API 端点 — 粘贴直接访问 TMDb API 的 URL（例如热门电影、高分电影、正在热映或特定合集）。需在设置选项卡中填写 TMDb API 读取访问令牌。
video_library 本地
使用 Emby 中已有的播放列表或合集作为来源。列表中的每个项目都会添加配置的标签。您也可以用它将合集显示为主屏幕上的一个栏目，详见下方的主屏幕栏目 — 合集模式。
tune MediaInfo
根据您自己的文件属性构建列表，例如“所有 4K HDR 电影”或“我还没看过的动作片”。可按视频画质、音频格式、类型、演员、评分等条件筛选。
auto_awesome AI 生成列表
用自然语言描述需求，例如“90 年代最佳科幻电影”，让 OpenAI 或 Google Gemini 生成列表。还可让 AI 参考特定用户近期观看的内容，提供个性化推荐。需在设置中填写 API 密钥。

启用开关 — 每个来源卡片顶部的复选框可启用或停用来源，而无需删除它。停用后，同步时会跳过该来源，并自动从所有项目中移除其标签和合集。适合临时暂停来源（例如季节性列表）。
badge

label 标签选项卡
启用或禁用标签，并设置标签名称，即应用于 Emby 中每个匹配项目的隐藏标签。
collections_bookmark 合集选项卡
可将匹配项目归入 Emby 合集，并自定义名称、简介和海报。启用仅合集可跳过标签，仅维护合集。
calendar_month 计划选项卡
限制此来源的启用时间，例如仅在特定日期范围内或按周期在指定日期启用。添加优先覆盖后，此来源启用时将接管使用相同标签的其他来源。

tv 主屏幕选项卡
让此来源自动作为一个栏目显示在指定用户的主屏幕上，每次同步时更新。选择媒体类型：合集可显示合集栏目，而非单个项目。
local_offer 标签与合集
什么是标签？ — 标签是 Emby 可附加到电影或剧集上的隐藏标记。正常浏览时不会看到它，但插件通过它判断项目属于哪个列表。主屏幕栏目依靠标签运作：一行会显示带有特定标签的所有项目。

标签 — 插件会为列表中的每个项目添加标签。当项目不再出现在列表中时（例如 Trakt 列表已更新），下次同步会自动移除该标签。

合集 — 除添加标签外（或替代标签），插件还可维护 Emby 合集。与标签一样，每次同步时都会自动添加和移除项目。

image
合集海报 — 上传本地图片或粘贴图片 URL，为合集设置自定义海报。海报保存在服务器上，每次同步时重新应用，确保不会被 Emby 覆盖。
tv

collections
主屏幕栏目 — 合集模式 — 想将整个合集显示为一行（而非单部电影）？使用本地合集来源，设置标签名称，并在主屏幕选项卡中选择媒体类型：合集。插件会为合集本身添加标签，而非其中的电影，让 Emby 将其显示为合集行。此模式不会为合集内的单部电影添加标签。
block
黑名单 — 黑名单选项卡中的 IMDB ID 将始终从此来源排除，即使它们出现在获取的列表中。
calendar_month 计划
来源默认始终启用。使用计划选项卡可限制来源的运行时间，例如仅在 10 月显示万圣节恐怖片列表，或仅在 12 月显示圣诞电影行。
all_inclusive
无计划 — 来源始终启用（默认）。
date_range
指定日期 — 来源仅在所选开始日期和结束日期之间启用。在此范围之外，标签和合集会自动移除。

周期性 — 在每周、每月或每年的指定日期启用。同一来源可叠加多个时间段，例如“每周五”和“每周六”。
workspace_premium
优先覆盖 — 当此来源处于计划启用时段内时，它会接管使用相同标签的其他来源，暂时停用其他来源。例如：“精选”来源全年运行，但启用优先覆盖的“万圣节精选”来源会在 10 月接管，自动以万圣节列表替换常规列表。
analytics MediaInfo 筛选器
MediaInfo 可根据您自己的文件属性构建列表，类似于创建智能搜索。例如：“所有我还没看过的 4K Dolby Vision 动作电影。”
规则工作原理：
  • 每条规则将一个属性与指定值进行比较（例如：类型 = 动作）。
  • 同一组内的规则可用与（必须全部匹配）或或（匹配任意一条）组合。
  • 多个组也可通过组间的连接符，以与 / 或组合。
  • 规则上的非按钮会反转规则，例如非 类型：喜剧会匹配喜剧以外的所有内容。
  • 文本字段（类型、演员、标题等）请每行输入一个值。匹配任意一行即可触发规则。
  • 文本字段提供包含（部分匹配）或精确（完全匹配）模式。
  • 数字字段（年份、评分、时长等）支持 = > ≥ < ≤。
视频
分辨率（4K、1080p、720p、SD、8K）、视频编码（HEVC/H.265、AV1、H.264）、HDR 类型（HDR10、Dolby Vision、HLG）

格式（Atmos、DTS-HD MA、TrueHD、DTS、AC3、AAC）、声道（7.1、5.1、立体声、单声道）、音频语言 — 每行一个语言代码（例如 swe、eng）

指标
社区评分、发行年份、时长（分钟）、添加日期（多少天前）、修改日期（多少天前）、文件大小（MB） — 均支持数值运算符
活动
已观看 / 未观看、上次播放（多少天前）、播放次数、看完人数（有多少用户已看完） — 可限定为任意用户、所有用户或特定用户

自动与手动 — 两项功能都会作为计划任务的一部分运行，也可随时通过运行按钮 → 同步主屏幕触发。
format_list_numbered 榜单
榜单是主屏幕上按名次排列的电影或剧集行，例如“我的十佳电影”。每张海报上都有数字角标（1、2、3…），表示其排名。插件会创建独立的 Emby 媒体库，其中包含上榜项目的快捷方式（不会复制或移动实际文件），并将该媒体库显示为专属主屏幕栏目。可在榜单选项卡中找到。

自动排除 — 榜单中的电影会自动从其他所有基于标签的主屏幕栏目中隐藏，避免同一部带排名角标的电影出现在其他行中。
tv
剧集榜单 — 每部上榜剧集都会在榜单专用媒体库中创建副本，包含带排名的海报和每一集的快捷方式。副本与原剧集共享观看状态和续播进度，同一剧集可出现在多个榜单中，每次同步都会添加新集。对所有用户，副本都会从搜索、最新、继续观看和接下来中排除（榜单媒体库会加入各用户的“最新”排除列表，Emby 也会将其应用于继续观看和接下来），避免单集重复显示。
build
同步榜单栏目 — 添加新的 Emby 媒体库后，如果主屏幕栏目出现同步异常，请运行同步榜单栏目任务（通过运行按钮或 Emby 的计划任务页面），重建所有排除设置。

play_circle
运行按钮 — 随时手动触发同步。提供三个选项：完整同步（所有内容）、同步主屏幕（仅更新主屏幕栏目，不更改标签）和同步标签和合集（更新标签和合集，跳过主屏幕）。
science
仅预览 — 标签/合集、动漫合集与主屏幕同步都只写日志，不实际改动。可在“设置”选项卡中启用。
bug_report
详细日志（扩展日志输出） — 为每个同步步骤记录更多详细信息。点击页面顶部的日志按钮即可查看。出现异常时，可用它了解插件的具体操作。
shield
结果为空时保留标签 — 如果来源返回零个项目（例如网站暂时无法访问），插件会保留现有标签和合集成员，而非全部移除。这样可防止网络波动导致意外清空。可在“设置”选项卡中启用。
save
备份与恢复 — 将插件配置（设置、API 密钥、标签和合集组、已保存的筛选器、榜单及主屏幕同步）导出为文件，或从之前的备份中选择恢复任意部分。位于设置选项卡底部。建议在进行较大更改前先备份。
